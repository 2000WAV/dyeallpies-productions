Preview:
An open-source 3D character controller as part of
2019 Godot Kickstarter campaign
and was released by GDQuest in
2020
. This submission does not include the code or Godot demo project, but the mannequin character with basic animations.
ASSET(S):
The .zip file include .glb file which was exported from the source file in Blender 4.2 LTS with some alpha value change to the materials to make the character visible when shaded.
The .blend file (v0.4.0) of the character/mannequin which was made in Blender 2.80 which have twelve (12) animation:
air_jump
air_jump_anticipation
air_land
dash
fight_idle
fight_kick
fight_punch
idle
idle_to_fight
jump_full
run
walk
