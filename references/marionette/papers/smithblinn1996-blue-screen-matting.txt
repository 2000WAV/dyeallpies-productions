APPLICABILITY
It is clear that the technique described here does not work unless
the foreground object is constant as the different backings are sub-
stituted behind it. We were explicit in [the preceding paper] that
this precludes use of the technique on non-rigidly moving fore-
ground objects. A further condition on a foreground object that is
similar and should be made explicit is that it must not optically
distort the backings as seen through partially transparent parts of
the object. That is, the backing pixels are assumed to be fixed in
position, so the foreground object cannot move them via distor-
tion. This is not a problem if each backing is a constant color, but
it is relaxing this constancy condition to arbitrary backings that is
the power of our technique. These restrictions apply, of course, to
all the "triangulation" techniques of [the preceding paper], all spe-
cial cases of Theorem 5.
