# Emoji assets (Twemoji)

72×72 PNGs from [Twemoji](https://github.com/jdecked/twemoji) v15.1.0
(`https://cdn.jsdelivr.net/gh/jdecked/twemoji@15.1.0/assets/72x72/<codepoint>.png`),
overlaid next to the practice word so non-English-speaking viewers get the word's
meaning. The word→codepoint map lives in `tools/scripts/vowel_map.py` (`WORD_EMOJI`) —
when adding a word, download its PNG here and add the mapping.
